## In

1. **待确认行可区分：** 首页「最近交易」里，`state=PENDING` 的行必须同时满足：（a）行上有可见、可读的「待确认」标签；（b）金额不得使用与已确认支出相同的入账红字样式。`POSSIBLE_DUPLICATE` 等仍为 PENDING 的行同样适用。
2. **已确认行不退化：** `state=CONFIRMED` 的行保持现有已入账样式（支出红字 / 收入既有样式），不得被加上「待确认」标签。
3. **统计口径不变：** 本月支出、本月收入、本月结余仍只计 `CONFIRMED`；待确认角标口径不变。不做新的合计指标。
4. **点击：** 点击待确认行进入该笔待确认详情（可走既有「确认 / 改完再记 / 忽略」或疑似重复的「查看重复 / 忽略」），不得当成已入账只读详情。点击已确认行仍进交易详情。
5. **文档：** 允许本刀 PR 修改 `docs/06` §4.1（必要时 `docs/05` 颜色/标签 token），写明上述视觉与点击规则。Proof 提交进 `docs/proof/ux-1/`。
