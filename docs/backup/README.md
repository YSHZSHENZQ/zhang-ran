## 2. 冻结时已生效的关键规则（SSOT 位置）

| 规则 | 值 | SSOT |
|---|---|---|
| 金额单位 | `Long amountMinor` = 货币最小单位（分） | `03` §4 |
| 决策点 | Domain 的 Decision 环节（Dedup 之后、Repository 之前） | `03` §16 |
| 置信度阈值 | `overallConfidence < 0.8` → Pending（可配置）；关键字段 `confidence < 0.5` → 整笔 Pending | `03` §16 |
| 去重 | 三级判定 + 交易时间差绝对值 ≤ 180 秒 + 最近 7 天范围 | `03` §12 |
| 用户修改保护 | 字段级 `FieldEdit` + `confirmedByUser` | `03` §11 |
| 退款 | 按退款发生月冲减；部分退款累计 ≤ 原金额；不计预算占用 | `02` §7/§14 |
| 转账 | 单条记录 + `sourceAccountId`/`targetAccountId`；`categoryId` 必须为空 | `03` §5/§13 |
| 预算 | `scope = TOTAL \| CATEGORY`，`period = MONTH`，两者独立不叠加 | `03` §9 |
| 采集来源 | 上游 AutoAccounting 模块化核心（Hook / 无障碍 / OCR / 短信），账然不自建 | `07` §1/§5/§9 |
| 隐私 | 不申请 INTERNET 权限；原始通知不上传 | `02` §18 |
